## 🚀 Featured Projects

### 🛡️ AI-Powered Job Scam Detection System *(Final Year — Ongoing)*
`React Native` `FastAPI` `DistilBERT` `OpenCV` `RabbitMQ` `MongoDB` `Docker`

A 4-component AI ecosystem that detects recruitment fraud across multiple vectors. I lead the **Scam Communication Detection** component.

- Fine-tuning a **DistilBERT** model for simultaneous **binary scam classification** and **multi-label psychological tactic detection** (urgency pressure, FOMO, sunk-cost influence, social proof)
- Built an **OCR pipeline** with **OpenCV + Tesseract** to extract text from screenshots — works across any messaging platform without API access
- React Native frontend with 3 input modes: built-in chat, paste message, and screenshot upload with real-time scam warnings
- FastAPI microservices with RabbitMQ for asynchronous inter-service communication

### 🎟️ Event Management System
`React` `Node.js` `Express` `MongoDB` `RabbitMQ` `Docker` `AWS` `CI/CD`

Full-stack microservices platform with **6 independent services**: API Gateway, Booking, Event, Notification, Review, and User.

- API Gateway handles routing, CORS, and JWT token validation across all services
- RabbitMQ for async messaging — booking confirmations, review subscriptions
- Docker Compose for local orchestration; deployed on **AWS** with **190+ commits**
- CI/CD via **GitHub Actions** with **SonarCloud** code quality gates
